# 版本 0.2.2 发布说明

## 概述

本次更新主要优化了裁剪工具的交互体验，使其更加直观和易用。

## 主要改进

### 裁剪工具交互优化

之前的裁剪工具需要用户手动确认裁剪操作，现在改为更直观的交互方式：

1. **左键拖动选择区域**
   - 按住左键并拖动鼠标选择裁剪区域
   - 实时显示选择框（白色虚线）
   - 释放左键后立即执行裁剪

2. **自动执行裁剪**
   - 无需额外确认步骤
   - 保留选中区域，删除其余部分
   - 自动重新适配视图

3. **历史管理集成**
   - 裁剪操作自动保存到历史
   - 支持撤销（Ctrl+Z）和重做（Ctrl+Y）
   - 与其他编辑操作无缝集成

## 技术改进

### 新增方法

1. **ImageData.crop_in_place()**
   ```python
   def crop_in_place(self, x: int, y: int, width: int, height: int):
       """原地裁剪图片（修改当前对象）"""
   ```
   - 直接修改当前图片对象
   - 更新图片尺寸
   - 清除临时图层

2. **CropTool.confirm_crop()**
   ```python
   def confirm_crop(self) -> bool:
       """确认裁剪（右键点击）"""
   ```
   - 验证是否有有效的裁剪区域
   - 返回布尔值指示是否可以执行裁剪

### 修复的问题

1. **裁剪矩形计算修正**
   - 之前：从 (2,2) 到 (6,6) 计算为 4x4
   - 现在：从 (2,2) 到 (6,6) 正确计算为 5x5
   - 修复方法：`width = abs(x2 - x1) + 1`

## 使用示例

### 基本用法

```python
# 1. 激活裁剪工具（快捷键 C）
# 2. 按住左键拖动选择区域
# 3. 释放左键立即执行裁剪
# 4. 如需撤销，按 Ctrl+Z
```

### 代码示例

```python
from src.models.image_data import ImageData
from src.models.crop_tool import CropTool

# 创建图片和工具
image = ImageData(pixels)
crop_tool = CropTool()

# 选择区域
crop_tool.start_selection(10, 10)
crop_tool.update_selection(50, 50)
crop_tool.end_selection()

# 确认裁剪
if crop_tool.confirm_crop():
    x, y, w, h = crop_tool.get_crop_rect()
    image.crop_in_place(x, y, w, h)
```
