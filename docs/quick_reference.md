# 快速参考

## 快捷键

| 功能 | 快捷键 |
|------|--------|
| 打开文件 | `Ctrl+O` |
| 保存文件 | `Ctrl+S` |
| 另存为 | `Ctrl+Shift+S` |
| 后退（撤销） | `Ctrl+Z` |
| 前进（重做） | `Ctrl+Y` |
| 画笔工具 | `B` |
| 裁剪工具 | `C` |
| 平移视图 | `Space + 拖动` 或 `中键拖动` |
| 缩放视图 | `鼠标滚轮` |

## 工具使用

### 画笔工具 (B)

1. 进入编辑模式
2. 按 `B` 激活画笔工具
3. 左键拖动绘制
4. 调整画笔大小、硬度、颜色

**特点：**
- 支持黑色和白色两种颜色
- 可调节画笔大小（1-500 像素）
- 可调节硬度（0.0-1.0）
- 实时预览画笔光标

### 裁剪工具 (C)

1. 进入编辑模式
2. 按 `C` 激活裁剪工具
3. **左键拖动**选择裁剪区域
4. **释放左键**立即执行裁剪
5. 支持撤销/重做

**特点：**
- 保留选中区域，删除其余部分
- 自动重新适配视图
- 实时显示选择框
- 支持历史管理
- 一步完成，无需额外确认

## 二值化方法

| 方法 | 说明 | 适用场景 |
|------|------|----------|
| 固定阈值 | 使用指定阈值 | 简单场景，光照均匀 |
| 自适应阈值 | 根据局部区域计算 | 光照不均匀（默认） |
| Otsu 阈值 | 自动计算最优阈值 | 双峰直方图 |
| Sauvola 阈值 | 局部自适应算法 | 文档图像 |
| Wolf 阈值 | 改进的局部算法 | 低对比度图像 |
| Nick 阈值 | 负偏移局部算法 | 噪声图像 |
| Bernsen 阈值 | 基于对比度 | 高对比度区域 |

## 预处理参数

| 参数 | 范围 | 默认值 | 说明 |
|------|------|--------|------|
| 曝光度 | -100 到 100 | 0 | 调整图像亮度 |
| 对比度 | -100 到 100 | 0 | 调整对比度 |
| 锐化 | 0 到 100 | 0 | 增强边缘清晰度 |
| 伽马 | 0.1 到 3.0 | 1.0 | 非线性亮度调整 |
| 平滑 | 0 到 100 | 0 | 降噪处理 |

## 工作流程

### 基本流程

```
1. 打开图片 (Ctrl+O)
   ↓
2. 调整预处理参数
   ↓
3. 选择二值化方法
   ↓
4. 进入编辑模式
   ↓
5. 使用画笔/裁剪工具编辑
   ↓
6. 保存图片 (Ctrl+S)
```

### 推荐流程

```
1. 打开原始图片
   ↓
2. 预处理优化
   - 调整曝光度和对比度
   - 适当锐化
   - 必要时降噪
   ↓
3. 二值化处理
   - 尝试不同方法
   - 选择效果最好的
   ↓
4. 精细编辑
   - 使用画笔修正细节
   - 使用裁剪去除多余部分
   ↓
5. 保存结果
```

## 常见问题

### Q: 如何撤销裁剪操作？
A: 按 `Ctrl+Z` 或点击"← 后退"按钮

### Q: 裁剪后图片太小看不清？
A: 裁剪后会自动重新适配视图，也可以使用鼠标滚轮放大

### Q: 如何取消裁剪选择？
A: 释放左键后会立即执行裁剪，如需取消请在释放前按 `Esc` 键或切换工具

### Q: 画笔绘制不连续？
A: 调整画笔间距参数（默认 25%）

### Q: 二值化效果不理想？
A: 先调整预处理参数，再尝试不同的二值化方法

## 性能提示

1. **大图片处理**
   - 先裁剪到感兴趣区域
   - 降低预处理参数强度
   - 使用较小的画笔尺寸

2. **实时预览**
   - 预处理参数会实时更新
   - 二值化方法切换会重新计算
   - 编辑模式下禁用参数调整

3. **内存管理**
   - 历史记录限制为 50 条
   - 大图片会占用更多内存
   - 定期保存工作成果

## 技巧和窍门

1. **精确裁剪**
   - 放大视图后再选择裁剪区域
   - 使用网格对齐（如果实现）

2. **画笔技巧**
   - 硬度 1.0 = 完全硬边
   - 硬度 0.5 = 柔和边缘
   - 小画笔 + 放大视图 = 精细编辑

3. **二值化优化**
   - 先增强对比度
   - 再适当锐化
   - 最后选择合适的二值化方法

4. **批量处理**
   - 记录最佳参数组合
   - 对相似图片使用相同参数
   - 考虑编写脚本自动化
