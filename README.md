# BinarizationTool - 二值化图片编辑器

基于 PySide6 的二值化图片编辑应用程序，提供类似 Photoshop 的画笔编辑功能。

**版本**: v1.0.2.0  
**作者**: 夏次一定de  

## 功能特性

### 图片处理
- 加载和显示二值化图片（PNG, JPG, BMP）
- 支持拖放图片文件到预览区域
- 多种二值化算法（固定阈值、Otsu、自适应等 7 种方法）
- 丰富的预处理参数（曝光、对比度、锐化、伽马、平滑）
- 实时预览所有参数调整效果

### 编辑工具
- **画笔工具**：可调节大小（1-500）、硬度、颜色（黑/白）
  - 智能光标：圆圈指示器 + 红色十字准星（小画笔时）
  - 悬浮设置面板：鼠标悬停显示快速设置
  - 高性能：增量光栅化 + NumPy 向量化优化
- **裁剪工具**：拖动选择区域，释放立即裁剪
- **独立编辑图层**：画笔编辑不受二值化参数影响

### 交互功能
- 缩放和平移视图（鼠标滚轮 + 空格拖动）
- 完整的撤销/重做功能
- 自动保存为新文件（文件名_时间戳格式）
- 无需切换模式，工具可直接使用

## 使用说明

### 基本工作流程

1. **打开图片**: 文件 → 打开，或直接拖放图片到预览区
2. **调整二值化**: 在左侧面板选择二值化方法和参数
3. **使用工具**: 直接选择画笔（B）或裁剪（C）工具，无需切换模式
4. **画笔编辑**: 
   - 鼠标悬停在画笔按钮上可快速调整大小和颜色
   - 在图片上绘制，编辑内容不受二值化参数影响
5. **保存图片**: Ctrl+S 自动另存为新文件（原文件名_时间戳）

### 快捷键

- `Ctrl+O`: 打开文件
- `Ctrl+S`: 保存文件（自动另存为）
- `Ctrl+Shift+S`: 另存为
- `Ctrl+Z`: 后退（撤销）
- `Ctrl+Y`: 前进（重做）
- `B`: 选择画笔工具
- `C`: 选择裁剪工具
- `Space + 拖动`: 平移视图
- `鼠标滚轮`: 缩放视图

### 画笔工具

- 左键拖动绘制
- 鼠标悬停在画笔按钮上显示设置面板
- 可调节画笔大小（1-500）、颜色（黑/白）
- 智能光标：圆圈 + 十字准星（小画笔时）
- 画笔编辑的内容完全不受二值化参数影响

### 裁剪工具

- 选择裁剪工具（快捷键 C）
- 按住左键拖动选择裁剪区域
- 释放左键后立即执行裁剪（保留选中区域，删除其余部分）
- 裁剪后图片会自动重新适配视图
- 支持撤销/重做
