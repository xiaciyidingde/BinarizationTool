# BinarizationTool - 二值化图片编辑器

基于 PySide6 的二值化图片编辑应用程序，提供类似 Photoshop 的画笔编辑功能。

**版本**: v1.1.0.0  
**作者**: 夏次一定de  

## 功能特性

### 图片处理
- 加载和显示二值化图片（PNG, JPG, BMP）
- 支持拖放图片文件到预览区域
- 多种二值化算法（固定阈值、Otsu、自适应等 7 种方法）
- 丰富的预处理参数：
  - 曝光、对比度、锐化、伽马、平滑
  - 降噪（6种方法）：高斯、中值滤波、双边滤波、NLMeans、形态学开/闭运算
- 实时预览所有参数调整效果

### 编辑工具
- **画笔工具**：可调节大小（1-500）、硬度、颜色（黑/白）
  - 智能光标：彩色圆圈指示器 + 十字准星（小画笔时）
  - 颜色指示：红色=黑色画笔，绿色=白色画笔
  - 悬浮设置面板：鼠标悬停显示快速设置
  - 快捷键支持：
    - `Ctrl+X`：切换黑白颜色
    - `Ctrl+↑/↓`：调整画笔大小（智能步长）
  - 高性能：增量光栅化 + NumPy 向量化优化
- **裁剪工具**：拖动选择区域，释放立即裁剪
- **选择工具**：智能选择指定颜色的像素
  - 圆圈光标指示选择范围
  - 可调节范围大小（1-500像素）
  - 两种模式：添加（绿色）/删除（红色）
  - 快捷键切换模式和调整大小：
    - `Ctrl+X`：切换添加/删除模式
    - `Ctrl+↑/↓`：调整选择范围（智能步长）
  - 悬浮设置面板快速调整
  - **支持拖动选择**：按住左键拖动连续选择多个区域
  - 点击选择指定颜色的像素（在圆圈范围内）
  - 支持反选、取消选择
  - 按颜色全局选择（黑色/白色）
  - 选区以红色覆盖层显示（高性能）
  - **填充选区**：快速填充选区为黑色或白色
- **独立编辑图层**：画笔编辑不受二值化参数影响

### 交互功能
- 缩放和平移视图（鼠标滚轮 + 空格拖动）
- 完整的撤销/重做功能
- 自动保存为新文件（文件名_时间戳格式）
- 无需切换模式，工具可直接使用

## 使用说明

### 基本工作流程

1. **打开图片**: 文件 → 打开（Ctrl+O），或直接拖放图片到预览区
2. **调整二值化**: 在左侧面板选择二值化方法和参数
3. **使用工具**: 直接选择画笔（B）或裁剪（C）工具，无需切换模式
4. **画笔编辑**: 
   - 鼠标悬停在画笔按钮上可快速调整大小和颜色
   - 在图片上绘制，编辑内容不受二值化参数影响
5. **保存图片**: 
   - 第一次保存（Ctrl+S）：自动生成带时间戳的新文件名
   - 之后保存：直接覆盖，无需重复选择

### 快捷键

- `Ctrl+O`: 打开文件
- `Ctrl+S`: 保存文件（第一次另存为，之后覆盖）
- `Ctrl+Shift+S`: 另存为
- `Ctrl+Z`: 后退（撤销）
- `Ctrl+Y`: 前进（重做）
- `B`: 选择画笔工具
- `C`: 选择裁剪工具
- `W`: 选择选择工具
- `Ctrl+X`: 切换画笔颜色（黑/白）或选择模式（添加/删除）
- `Ctrl+Shift+X`: 切换选择目标颜色（黑色/白色）
- `Ctrl+↑`: 增大画笔/选择范围
- `Ctrl+↓`: 减小画笔/选择范围
- `Ctrl+D`: 取消选择
- `Ctrl+Shift+I`: 反选
- `Space + 拖动`: 平移视图
- `鼠标滚轮`: 缩放视图

### 画笔工具

- 左键拖动绘制
- 鼠标悬停在画笔按钮上显示设置面板
- 可调节画笔大小（1-500）、颜色（黑/白）
- 智能光标：彩色圆圈 + 十字准星（小画笔时）
  - 红色光标 = 黑色画笔（绘制黑色像素）
  - 绿色光标 = 白色画笔（绘制白色像素）
- 画笔编辑的内容完全不受二值化参数影响

### 裁剪工具

- 选择裁剪工具（快捷键 C）
- 十字光标指示裁剪模式
- 按住左键拖动选择裁剪区域
- 释放左键后立即执行裁剪（保留选中区域，删除其余部分）
- 裁剪后图片会自动重新适配视图
- 支持撤销/重做

### 选择工具

- 选择选择工具（快捷键 W）
- 智能光标指示器：
  - 外圈颜色：绿色=添加模式，红色=删除模式
  - 中心圆点：黑色=选择黑色块，白色=选择白色块
- **点击或拖动**选择区域：
  - 单击：在点击位置选择指定颜色的像素（在圆圈范围内）
  - 按住左键拖动：连续选择多个区域（类似画笔）
- 只选择指定目标颜色的像素（黑色或白色）
- 选择范围限制在圆圈指示器内，不扩展到整个连续块
- 选区以红色覆盖层显示（高性能渲染）
- 可调节选择范围大小（1-500像素）
- 支持两种选择模式：
  - 添加模式（绿色外圈）：添加到选区
  - 删除模式（红色外圈）：从选区减去
- 支持两种目标颜色：
  - 黑色（黑色中心点）：只选择黑色像素
  - 白色（白色中心点）：只选择白色像素
- 快捷键：
  - `Ctrl+X`：切换添加/删除模式
  - `Ctrl+Shift+X`：切换目标颜色（黑色/白色）
  - `Ctrl+↑/↓`：调整选择范围（智能步长）
- 鼠标悬停在选择按钮上显示设置面板
- 支持取消选择（Ctrl+D）、反选（Ctrl+Shift+I）
- 可以按颜色全局选择（选择菜单 → 选择黑色/白色）
- **填充选区**：
  - 在设置面板中点击"填充黑色"或"填充白色"按钮
  - 填充后自动清除选区，立即看到效果
  - 填充内容保存到编辑图层，不受二值化参数影响
  - 支持撤销/重做（Ctrl+Z）
